📋 WHAT IS THIS?

A tool that captures and validates Google Tag Manager events on Shopify
websites - even when GTM Preview mode doesn't work (Custom Pixel issue).

Problems it solves:
  ❌ GTM Preview doesn't work with Shopify Custom Pixels
  ❌ Can't see what tags are firing
  ❌ Manual console checking is tedious
  ❌ No systematic validation approach

What it does:
  ✅ Automatically captures console events
  ✅ Records all clicks and interactions
  ✅ Sends data to Google Sheets
  ✅ Generates validation reports

═══════════════════════════════════════════════════════════════════════

⚡ 30-SECOND QUICKSTART

1. Deploy webhook: https://script.google.com/ (see QUICK_START.md)
2. Copy webhook URL
3. Configure: Use src/browser/configHelper.js OR edit devtoolsSnippet.js
4. Run snippet in browser DevTools
5. Events automatically captured!

Full instructions: TLDR.md or QUICK_START.md
